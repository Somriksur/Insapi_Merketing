================================================================
  HOW TO RUN THE APP (DEV MODE)
================================================================

--- MAC (Terminal 1 — Backend) ---
  cd backend
  source .venv/bin/activate
  uvicorn server:app --host 0.0.0.0 --port 8000 --reload

--- MAC (Terminal 2 — Frontend) ---
  cd frontend
  npm start

Then open browser at: http://localhost:3000
----------------------------------------------------------------

--- WINDOWS (Terminal 1 — Backend) ---
  cd backend
  .venv\Scripts\activate
  uvicorn server:app --host 0.0.0.0 --port 8000 --reload

--- WINDOWS (Terminal 2 — Frontend) ---
  cd frontend
  npm start

Then open browser at: http://localhost:3000
----------------------------------------------------------------

NOTE: frontend/.env must have:
  REACT_APP_BACKEND_URL=http://127.0.0.1:8000

================================================================
  WINDOWS FIRST-TIME SETUP (run once before dev mode)
================================================================

Prerequisites (install these first):
  1. Python 3.11+  -->  https://www.python.org/downloads/
                        CHECK "Add Python to PATH" during install!
  2. Node.js LTS   -->  https://nodejs.org/en/download/
                        npm is included automatically.
  3. Git (optional) --> https://git-scm.com/download/win

--- Backend setup (run in Command Prompt / PowerShell) ---
  cd backend
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt

--- Frontend setup ---
  cd frontend
  npm install

--- Verify setup ---
  python --version        (should say 3.11 or higher)
  node --version          (should say 18 or higher)
  npm --version           (should say 9 or higher)
